Bu proje kapsamında, siber olaylara müdahale süreçlerini otomatikleştirmek amacıyla Shuffle SOAR platformunun sıfırdan kurulumunu ve temel yapılandırmasını gerçekleştirdim. Kullanıcı hesaplarının oluşturulması ve yetkilendirme süreçlerini yönettikten sonra; EPP, EDR, NDR, SIEM, Güvenlik Duvarı, NAC, DLP ve Active Directory gibi kritik kurumsal güvenlik çözümlerini SOAR platformuna entegre ettim.

Yerel API desteği olmayan sistemler için özel entegrasyon modülleri ve API bağlantıları geliştirerek, olay yönetimini otomatikleştiren özel playbook'lar ve iş akışları tasarladım. Ayrıca, regex ve gelişmiş veri işleme teknikleri kullanarak olay günlüklerinden anlamlı veriler çıkarılmasını sağlayıp, koşullu dallanma ve tetikleyiciler ile manuel müdahale sürelerini minimuma indiren uçtan uca otomasyon süreçleri oluşturdum. Within the scope of this project, I performed a clean deployment and configuration of the Shuffle SOAR platform to automate cyber incident response processes. After setting up user management and access privileges, I successfully integrated critical enterprise security systems including EPP, EDR, NDR, SIEM, Firewalls, NAC, DLP, and Active Directory into the orchestrator.

I designed custom integration modules and API connectors for systems lacking native API interfaces to create bespoke automated incident playbooks and workflows. Additionally, utilizing regex parsing and advanced data filtering, I extracted actionable logs and engineered end-to-end automation workflows that reduce manual response times through conditional logic and active triggers. Im Rahmen dieses Projekts habe ich eine vollständige Bereitstellung und Konfiguration der Shuffle SOAR-Plattform durchgeführt, um Prozesse zur Reaktion auf Cyber-Vorfälle (Incident Response) zu automatisieren. Nach der Einrichtung der Benutzerverwaltung und der Zugriffsprivilegien habe ich kritische Sicherheitslösungen wie EPP, EDR, NDR, SIEM, Firewalls, NAC, DLP und Active Directory erfolgreich in den Orchestrator integriert.

Ich habe benutzerdefinierte Integrationsmodule und API-Konnektoren für Systeme ohne native API-Schnittstellen entwickelt, um maßgeschneiderte automatisierte Playbooks und Workflows zu erstellen. Darüber hinaus habe ich unter Verwendung von Regex-Analysen und fortschrittlicher Datenfilterung relevante Logs extrahiert und End-to-End-Automatisierungs-Workflows entwickelt, die die manuellen Reaktionszeiten durch bedingte Logik und aktive Trigger minimieren. 在该项目下，我从零开始部署和配置了 Shuffle SOAR 平台，以实现网络安全事件响应流程的自动化。在完成用户管理与权限配置后，我成功将 EPP、EDR、NDR、SIEM、防火墙、NAC、DLP 和 Active Directory 等关键企业安全解决方案集成到该编排器中。

针对缺乏原生 API 接口的系统，我设计了自定义集成模块和 API 连接器，以创建定制的事件处置剧本（Playbooks）和自动化工作流。此外，我利用正则表达式解析和高级数据过滤提取了关键日志，并构建了端到端自动化流程，通过条件逻辑和活动触发器将人工响应时间降至最低。 В рамках этого проекта я выполнил чистую установку и базовую конфигурацию платформы Shuffle SOAR с целью автоматизации процессов реагирования на киберинциденты. После создания учетных записей пользователей и управления процессами авторизации я интегрировал критически важные корпоративные решения безопасности, такие как EPP, EDR, NDR, SIEM, межсетевые экраны, NAC, DLP и Active Directory в платформу SOAR.

Разработав специальные модули интеграции и API-подключения для систем без встроенной поддержки API, я спроектировал кастомные сценарии (playbooks) и рабочие процессы, автоматизирующие управление инцидентами. Кроме того, используя регулярные выражения и передовые методы обработки данных, я обеспечил извлечение значимых данных из журналов инцидентов и создал сквозные процессы автоматизации с условным ветвлением и триггерами, которые сжимают время ручного вмешательства.

Fenerbahçe Üniversitesi Sistem ve Ağ Uzmanlığı laboratuvar sınıfında gerçekleştirdiğim bu çalışmada, Nessus Zafiyet Tarama yazılımının kurulumunu, yapılandırmasını ve detaylı kullanımını yönettim.

Zafiyetli olarak yapılandırılmış Linux, Windows işletim sistemleri ve web uygulaması makinelerini Nessus ile tarayarak kritik güvenlik açıklarını tespit ettim. Çıkan tarama sonuçlarını profesyonel standartlarda raporlaştırıp analiz ettim. Ardından, bulunan zafiyetlerden (exploit) yararlanarak Kali Linux ve çeşitli sızma teknikleri vasıtasıyla hedef makinelere sızma testleri gerçekleştirip güvenlik açıklarının kapatılmasına yönelik çözüm yollarını doğruladım. In this lab project executed during the System and Network Engineering program at Fenerbahçe University, I managed the deployment, tuning, and rigorous operation of the Nessus Vulnerability Scanner.

I scanned purposefully vulnerable Linux, Windows machines, and web applications with Nessus to map out critical and high-severity security vulnerabilities. The results were professionally audited, categorized, and documented. Following this, using Kali Linux and custom exploits, I performed penetration tests to confirm access paths and validate mitigation strategies to seal off active vulnerabilities. In diesem Laborprojekt, das während des Programms für System- und Netzwerktechnik an der Fenerbahçe-Universität durchgeführt wurde, habe ich die Bereitstellung, Feinabstimmung und den Betrieb des Nessus Vulnerability Scanners geleitet.

Ich habe gezielt anfällige Linux- und Windows-Maschinen sowie Webanwendungen mit Nessus gescannt, um kritische und schwerwiegende Sicherheitslücken aufzudecken. Die Ergebnisse wurden professionell geprüft, kategorisiert und dokumentiert. Anschließend habe ich unter Verwendung von Kali Linux und gängigen Exploits Penetrationstests durchgeführt, um Angriffsvektoren zu bestätigen und Gegenmaßnahmen zur Schließung der Schwachstellen zu validieren. 在费内巴切大学系统与网络工程课程期间进行的这个实验室项目中，我负责了 Nessus 漏洞扫描器的部署、微调和严格运行。

我使用 Nessus 扫描了故意配置漏洞的 Linux、Windows 机器和 Web 应用程序，以定位关键和高危安全漏洞。扫描结果经过了专业审计、分类和归档。随后，使用 Kali Linux 和自定义漏洞利用工具，我进行了渗透测试，以确认入侵路径并验证安全加固策略，从而封锁活跃的漏洞。 В этой работе, которую я провел в лаборатории системной и сетевой инженерии Университета Фенербахче, я руководил установкой, настройкой и детальным использованием сканера уязвимостей Nessus.

Я сканировал намеренно уязвимые операционные системы Linux, Windows и веб-приложения с помощью Nessus для выявления критических брешей в безопасности. Результаты сканирования были проанализированы и оформлены в отчет в соответствии с профессиональными стандартами. Затем, используя Kali Linux и различные методы тестирования на проникновение путем эксплуатации обнаруженных уязвимостей, я провел пентесты целевых машин и подтвердил эффективность решений по устранению этих уязвимостей.
